# Mock Board updates

This version adds:
- Mock Board item choices: 25, 50, 75, 100, 150, 200, 250, 300, 350, 400, 420.
- Countdown display in HH:MM:SS format.
- Active mock exam persistence in localStorage.
- Answers, current question, timer deadline, and results survive accidental page refreshes.
- Item option buttons wrap on smaller screens.

Replace the files in the existing GitHub/Vercel project with this folder's contents. Keep package.json and index.html at the repository root.
