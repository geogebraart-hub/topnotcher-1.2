# LET Genius Hub

A frontend-first React/Vite implementation inspired by the supplied LET Genius Hub screenshots.

## Included
- Dashboard / Daily Drill
- GenEd, ProfEd and Majorship category switching
- Daily drill question flow with answers and explanations
- Persistent streak, question, session and deck state via localStorage
- Progress dashboard with readiness metrics and charts
- Study Decks with search/filter/create/delete
- Mock Board Exam configuration and demo scoring
- Study Schedule calendar with add-event modal
- Responsive desktop/mobile layout
- Vercel-ready Vite project

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Put this folder in a GitHub repository.
2. Import the repository into Vercel.
3. Framework Preset: Vite.
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Deploy.

No API key is required for this frontend demo. Add a backend/database later for accounts, cloud-synced decks, real question banks, and real exam results.
