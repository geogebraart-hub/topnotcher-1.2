# Mock Board Question Bank Update

This version adds a built-in LET-style practice bank so Mock Board attempts can populate long exams independently of the number of questions in user-created Study Decks.

Built-in bank:
- GenEd: 156+ items
- ProfEd: 156+ items
- Majorship: 120 items
- Full Board pool: 432+ items

The existing user-created questions are also merged into the Mock Board pool.

Supported item counts remain 25, 50, 75, 100, 150, 200, 250, 300, 350, 400, and 420.
